# Burst notes: stable app API (gift cards, PIM products, app webhooks)

Commits on `burst/shared`: see `git log --grep "Stable app API"`.

## What changed
- New stable operations: `dashboard.resources.gift_cards.{list,get,create,adjust,update}`,
  `dashboard.resources.products.{create,update}`,
  `dashboard.resources.webhook_subscriptions.{list,create,update,delete}`.
- New scopes: `read_gift_cards`, `write_gift_cards` (Sensitive), `write_webhooks` (Sensitive).
  `isCapabilityScope` is now `sensitive && rbac.length === 0`.
- `webhooks` is no longer a reserved plugin RBAC resource; `dashboard.webhooks.*` moved to the
  internal tier instead, so apps reach only their own subscriptions.
- Migration 0161 (`webhook_subscriptions.plugin_id` + index), D1 and PostgreSQL sidecar, schema
  contract pinned at 161.
- Idempotency replay never stores a body flagged `idempotencySecretResponse` (webhook secret).
- `adjustGiftCardBalance` takes an optional `expectedVersion` guarded in the ledger batch.
- Base product section also replaces `description`, `metaTitle`, `metaDescription` (additive, beta).
