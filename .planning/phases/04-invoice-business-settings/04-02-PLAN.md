**`getOrAssignInvoiceNumber(db: Database, orderId: string, prefix?: string): Promise<{ invoiceNumber: number; formatted: string }>`:**

Logic (step by step):
1. Read `orders.invoiceNumber` for the given orderId: `db.select({ invoiceNumber: orders.invoiceNumber }).from(orders).where(eq(orders.id, orderId)).get()`
2. If `invoiceNumber` is NOT null, return it immediately: `{ invoiceNumber, formatted: formatInvoiceNumber(prefix ?? "INV", invoiceNumber) }`
3. If null, read the counter from settings: `db.select({ value: settings.value }).from(settings).where(and(eq(settings.category, "invoice_counter"), eq(settings.key, "current_value"))).get()`
4. If no counter row exists, this is the first invoice. Set `oldValue = "0"`, `newValue = 1`
5. If counter exists, `oldValue = row.value`, `newValue = parseInt(oldValue, 10) + 1`
6. **CAS write (counter):** If counter row exists, UPDATE with WHERE guard:
   ```typescript
   const result = await db.update(settings)
     .set({ value: String(newValue), updatedAt: sql`unixepoch()` })
     .where(and(
       eq(settings.category, "invoice_counter"),
       eq(settings.key, "current_value"),
       eq(settings.value, oldValue)
     ));
   ```
   If no counter row exists, INSERT:
   ```typescript
   await db.insert(settings).values({
     id: crypto.randomUUID(),
     key: "current_value",
     value: String(newValue),
     type: "string",
     category: "invoice_counter",
   });
   ```
7. **Write invoice number to order:** `db.update(orders).set({ invoiceNumber: newValue }).where(eq(orders.id, orderId))`
8. If prefix is not provided, read it from business settings: query `settings` where `category = "business_info"` and `key = "invoice_prefix"`. Default to `"INV"`.
9. Return `{ invoiceNumber: newValue, formatted: formatInvoiceNumber(resolvedPrefix, newValue) }`
