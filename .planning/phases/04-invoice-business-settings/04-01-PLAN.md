- Query all rows from `settings` table where `category = "business_info"`

  - `legal_name` -> `legalName` (default: `""`)
  - `address_line1` -> `addressLine1` (default: `""`)
  - `address_line2` -> `addressLine2` (default: `""`)
  - `city` -> `city` (default: `""`)
  - `state_region` -> `stateRegion` (default: `""`)
  - `postal_code` -> `postalCode` (default: `""`)
  - `country` -> `country` (default: `"Bangladesh"`)
  - `phone` -> `phone` (default: `""`)
  - `email` -> `email` (default: `""`)
  - `tax_id` -> `taxId` (default: `""`)
  - `invoice_prefix` -> `invoicePrefix` (default: `"INV"`)
  - `invoice_footer_text` -> `invoiceFooterText` (default: `""`)

- Key mapping is the reverse of the get function (camelCase -> snake_case)
