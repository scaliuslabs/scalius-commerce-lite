# @scalius/admin — Astro Admin Dashboard (Deprecated)

- **Port**: 4321 (dev)
- **Auth**: Better Auth (email/password + optional 2FA)

## Replacement

See [`apps/admin-v2/README.md`](../admin-v2/README.md) for the active admin dashboard built with TanStack Start, TanStack Router, and TanStack Query.
