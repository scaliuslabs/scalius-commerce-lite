# Contributing to the storefront

The storefront is part of the Scalius Commerce monorepo and follows the repository-wide contribution, licensing, issue-triage, testing, and security policies.

Read the root [contribution guide](../../CONTRIBUTING.md) before opening an issue or beginning invited work. Develop from the repository root with `pnpm`; do not treat this application as a separate MIT-licensed repository or target a separate `main` branch.

Storefront defects and proposals should use the repository's [structured issue forms](https://github.com/scaliuslabs/scalius-commerce-lite/issues/new/choose). Never include credentials, OTPs, receipt proofs, session tokens, or buyer personal data in an issue, pull request, screenshot, fixture, or log.
