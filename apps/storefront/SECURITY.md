# Security Policy

The storefront is part of the Scalius Commerce monorepo and follows the
repository-wide security policy. Read the root [SECURITY.md](../../SECURITY.md)
for supported versions, response timelines, scope, and safe harbor.

**Do not open a public GitHub issue for security vulnerabilities.** Report them
to **security@scalius.com** with a description, reproduction steps or a
proof-of-concept, the impact, and the affected component (for example checkout,
cart, customer account, or discovery XML).

Do not include production credentials, raw buyer data, OTPs, receipt proofs, or
session tokens in the initial report. We will arrange a safer transfer if
sensitive evidence is required.
