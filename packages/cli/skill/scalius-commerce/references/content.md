# Content

- Resolve the current bounded entity and revision before editing.
- Pages and articles share the reviewed content operations; preserve type, status, discovery, canonical-path, and revision semantics.
- Navigation edits use reusable menus/items. Read move options before moving an item; publish only after the draft is coherent.
- Theme work uses draft → optional rebase → publish, with exact revision control. Theme preview is a secure body-only browser continuation; never print or persist its code.
- Media follows the catalog media policy. Upload first, then reference committed media IDs.
- Prefer semantic header/footer/homepage reads over legacy unbounded aggregates.
- After writes, verify the bounded read and public projection when visibility changed.
