# Sales workflows

Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.
scalius_search ranks these; a confident hit inlines its plan and all its rules. [approval] marks a step that needs the merchant's approval.

### Fulfill an order (`dashboard.order-fulfill`)
ops: dashboard.orders.get -> dashboard.orders.fulfillment_create
- Read the exact order and current fulfillment state first.

### Create a provider shipment (`dashboard.order-provider-shipment`)
ops: dashboard.orders.get -> dashboard.orders.create_shipment -> dashboard.orders.shipments
- Read the exact current order and selected provider first.

### Refund an order payment (`dashboard.order-refund`)
ops: dashboard.orders.payments -> dashboard.orders.refund[approval] -> dashboard.orders.refund_reconcile[approval]
- Resolve the exact captured payment and validate the refund amount.

### Process an order return (`dashboard.order-return`)
ops: dashboard.orders.return_create -> dashboard.orders.return_approve -> dashboard.orders.return_receive -> dashboard.orders.return_get
- Require exact order items, quantities, reason, and disposition.

### Issue an order invoice (`dashboard.invoice-issue`)
ops: dashboard.orders.invoice_get -> dashboard.orders.invoice_issue -> dashboard.orders.invoice_print
- Review the exact draft invoice before issuing it.

### Create and activate a discount (`dashboard.discount-lifecycle`)
ops: dashboard.discounts.create -> dashboard.discounts.preview -> dashboard.discounts.activate -> dashboard.discounts.get
- Create a draft from complete merchant-supplied discount facts.

### Turn a discount on or off (`dashboard.discount-toggle`)
ops: dashboard.discounts.list -> dashboard.discounts.activate -> dashboard.discounts.pause -> dashboard.discounts.get
- Resolve exactly one matching discount before mutation.

### Customer order history (`dashboard.customer-history`)
ops: dashboard.customers.list -> dashboard.customers.history
- Resolve one exact customer before reading history.

### Tag many customers (`dashboard.customer-bulk-tag`)
ops: dashboard.resources.customers.bulk_tag -> dashboard.resources.bulk_runs.get
- Use filter.minOrders / filter.maxOrders for order-count rules ('more than 3 orders' is minOrders 4).

### Answer customer messages (`dashboard.inbox-reply`)
ops: dashboard.conversations.list -> dashboard.conversations.get -> dashboard.conversations.context -> dashboard.conversations.post
- Needs a Custom grant with the customer_conversations scope; a preset grant is refused.

### Cancel a customer order (`dashboard.order-cancel`)
ops: dashboard.orders.list -> dashboard.orders.get -> dashboard.orders.update_status
- Find the order by number with dashboard.orders.list, then set status cancelled with a reason and the order's version.

### Place an order for a customer (`dashboard.order-for-customer`)
ops: dashboard.customers.list -> dashboard.products.list_summaries -> dashboard.product_variants.list -> dashboard.resources.orders.create
- Resolve exactly one customer and exact SKU ids before placing the order; ask when several match.

### Moderate product reviews (`dashboard.reviews-moderate`)
ops: dashboard.reviews.list -> dashboard.reviews.moderate -> dashboard.reviews.reply -> dashboard.reviews.get
- Needs a Custom grant with the review_moderation scope; a preset grant is refused.
