# Content recipes

Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.

Each step is one call. answer = scalius_answer, search = scalius_search, read/verify = scalius_read, write = scalius_write, resource = an MCP resource, cli = the scalius CLI (ask, search, read, write, bulk, export).
Every write: dryRun first. [approval] = destructive or financial: the write answers with confirmation.approvalUrl: the merchant approves it there (or in the terminal dialog), then repeat the write with approvalId (CLI: --approval <id>). [ask first] = a security change: confirm with the merchant before it. rev = send the revision your read returned. needs = required inputs; scalius_describe gives the exact shape and an example.

## Create collection "Eid Picks" with 6 products and add it to the main menu
1. read   dashboard.collections.form_options: the 6 product ids
2. write  dashboard.collections.create needs body.name, body.presentation, body.isActive, body.config: isActive, presentation, config with the products
3. read   dashboard.navigation.menus_list: the main menu and its revision
4. write  dashboard.navigation.items_create rev; needs path.menuId, body.label, body.labelMode, body.target: labelMode resource, target the collection
5. write  dashboard.navigation.menus_publish rev; needs path.menuId
6. verify storefront.navigation.get: needs a storefront connection; else dashboard.navigation.items_list

## Change the homepage hero headline and publish the theme
1. read   dashboard.theme.workspace_get: draft and live revisions
2. read   dashboard.theme.document_get: the whole draft document
3. write  dashboard.theme.draft_save rev; needs body.theme, body.basePublishedRevision: the whole document with only the headline changed
4. write  dashboard.theme.publish rev: after the merchant sees the preview
5. verify dashboard.theme.workspace_get

## Write and publish an About Us page and link it in the footer
1. write  dashboard.content.create needs body.title, body.content, body.metaTitle, body.metaDescription: contentType page, isPublished true, the merchant's words
2. read   dashboard.navigation.placements_list: which menu is the footer
3. write  dashboard.navigation.items_create rev; needs path.menuId, body.label, body.labelMode, body.target: labelMode resource, target the page
4. write  dashboard.navigation.menus_publish rev; needs path.menuId
5. verify dashboard.content.get
