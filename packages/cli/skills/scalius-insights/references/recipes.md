# Insights recipes

Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.

Each step is one call. answer = scalius_answer, search = scalius_search, read/verify = scalius_read, write = scalius_write, resource = an MCP resource, cli = the scalius CLI (ask, search, read, write, bulk, export).
Every write: dryRun first. [approval] = destructive or financial: show confirmation.summary to the merchant, then send its confirmToken (CLI: --yes after they approve). [ask first] = a security change: confirm with the merchant before it. rev = send the revision your read returned. needs = required inputs; scalius_describe gives the exact shape and an example.

## How much did we sell today, and how many orders are unfulfilled?
1. answer "How much did we sell today?"
2. read   dashboard.orders.list: query {view:"unfulfilled", limit:1}: the count is meta.total

## Which 5 products have the lowest stock?
1. read   dashboard.inventory.list: query {section:"variants", sort:"available", order:"asc", limit:5}
Note: Rows are SKUs; name the product and option. Out-of-stock alerts: dashboard.inventory_alerts.list.

## What is left to set up before launch?
1. read   dashboard.setup.checklist

## Export last month's orders as CSV
1. cli    scalius export orders --since <first day> --until <last day> --out orders.csv
2. read   dashboard.orders.export: MCP: query {startDate, endDate}; returns a one-use file link
Note: Dates are YYYY-MM-DD in the store's time zone (scalius://store timeZone).
