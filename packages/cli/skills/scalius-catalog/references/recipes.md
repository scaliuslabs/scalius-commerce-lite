# Catalog recipes

Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.

Each step is one call. answer = scalius_answer, search = scalius_search, read/verify = scalius_read, write = scalius_write, resource = an MCP resource, cli = the scalius CLI (ask, search, read, write, bulk, export).
Every write: dryRun first. [approval] = destructive or financial: show confirmation.summary to the merchant, then send its confirmToken (CLI: --yes after they approve). [ask first] = a security change: confirm with the merchant before it. rev = send the revision your read returned. needs = required inputs; scalius_describe gives the exact shape and an example.

## Create a simple product "Cotton Panjabi", 1,500, 20 in stock, published
1. read   dashboard.settings.currency_get: prices use this currency
2. read   dashboard.categories.form_options: pick categoryId; ask if none fits
3. write  dashboard.products.create needs body.name, body.description, body.price, body.categoryId, body.isActive, body.freeDelivery, ...: isActive:true, price:1500, defaultSku {stock:20}, media:[] or committed images
4. verify dashboard.products.get_section: section base
Note: A simple product has exactly one hidden SKU: stock goes on defaultSku, never on the product.

## Create a t-shirt in S/M/L x red/blue, 800 each, 10 of each
1. search "create an optioned product"
2. resource scalius://workflows/catalog.optioned-product.v1: matrix rules
3. write  dashboard.products.create needs body.name, body.description, body.price, body.categoryId, body.isActive, body.freeDelivery, ...: optionMatrix: 2 axes, all 6 SKUs, price 800, stock 10
4. verify dashboard.products.get_section: section variants
Note: Every SKU picks one value of every axis, in axis order; send the whole matrix in one create.

## Upload 3 local photos as the product gallery
1. cli    scalius media upload a.jpg b.jpg c.jpg --yes: returns media ids
2. read   dashboard.products.get_section: section media: current gallery and revision
3. write  dashboard.products.update_section rev; needs path.id, path.section: section media with the new mediaIds
Note: Without a shell, import public HTTPS images with dashboard.media.import_url.

## Raise every Shoes price by 5% (show me first)
1. read   dashboard.products.list_summaries: query {category:<id>}: every page
2. read   dashboard.product_variants.list: each product's SKU prices
3. write  dashboard.product_variants.update rev; needs path.id, path.variantId, body.selectedOptionValueIds, body.imageId, body.weight, body.sku, ...: price x 1.05, rounded; batch up to 20 per call, dry run first
Note: Show the merchant the before/after list and get approval before the first write.

## Change the SEO title and description of Cotton Panjabi
1. read   dashboard.products.list_summaries: query {search:"Cotton Panjabi"}
2. read   dashboard.products.get_section: section text: current text and aggregateRevision
3. write  dashboard.products.update_section rev; needs path.id, path.section: section text, field metaTitle then metaDescription: replace the whole value

## Move 10 units of TS-RED-M from Dhaka to Chittagong
1. read   dashboard.inventory_locations.list
2. read   dashboard.resources.variants.lookup: the SKU id and stock by location
3. write  dashboard.inventory_transfers.create needs body.originLocationId, body.destinationLocationId: lines [{variantId, quantity:10}]
4. write  dashboard.inventory_transfers.ship rev; needs path.transferId
5. write  dashboard.inventory_transfers.receive needs path.transferId, body.lines: when the units arrive
6. verify dashboard.inventory_transfers.get
