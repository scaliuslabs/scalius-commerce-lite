# Settings recipes

Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.

Each step is one call. answer = scalius_answer, search = scalius_search, read/verify = scalius_read, write = scalius_write, resource = an MCP resource, cli = the scalius CLI (ask, search, read, write, bulk, export).
Every write: dryRun first. [approval] = destructive or financial: show confirmation.summary to the merchant, then send its confirmToken (CLI: --yes after they approve). [ask first] = a security change: confirm with the merchant before it. rev = send the revision your read returned. needs = required inputs; scalius_describe gives the exact shape and an example.

## Is checkout ready to take orders, and what is blocking it?
1. read   dashboard.checkout.readiness_get: status and issues
2. read   dashboard.payments.methods_get: only when an issue names payments
3. read   dashboard.shipping_methods.list: only when an issue names delivery

## Enable cash on delivery for Bangladesh only
1. read   dashboard.payments.methods_get: enabled methods and revision
2. write  dashboard.payments.methods_update rev; needs body.enabledMethods, body.defaultMethod: all enabled methods plus cod, defaultMethod, expectedRevision
3. verify dashboard.checkout.readiness_get
Note: COD is Bangladesh-only by its own country rule; nothing else to restrict.

## Delivery 60 inside Dhaka, 120 outside
1. read   dashboard.shipping_methods.list: existing zones
2. read   dashboard.delivery_locations.list: the Dhaka city place id
3. write  dashboard.shipping_zones.create needs body.name, body.rates: Inside Dhaka: locationIds [Dhaka], rate fee 60
4. write  dashboard.shipping_zones.create needs body.name, body.rates: Outside Dhaka: regions [{countryCode:BD}], rate fee 120
5. verify dashboard.shipping_methods.list
Note: A place zone beats the country zone; no zone means no delivery.

## Charge 5% VAT on Bangladesh orders
1. read   dashboard.taxes.settings_get: prices include tax or not (per market)
2. write  dashboard.taxes.regions_create needs body.countryCode: countryCode BD
3. read   dashboard.taxes.classes_list: the standard class
4. write  dashboard.taxes.rates_create needs body.taxClassId, body.taxRegionId, body.name, body.rateBps: name VAT, rateBps 500
5. verify dashboard.taxes.preview: a sample BD order

## Invite a staff member who can only manage orders
1. read   dashboard.team.roles.list: a role with only order permissions
2. write  dashboard.team.roles.create [ask first]; needs body.name, body.displayName: only if no role fits
3. write  dashboard.team.users.invite [ask first]; needs body.name, body.email, body.roleId: name, email, roleId
4. verify dashboard.team.users.list
