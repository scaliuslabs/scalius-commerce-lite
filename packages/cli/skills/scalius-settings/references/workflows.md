# Settings workflows (part 1)

Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.
scalius_search ranks these; a confident hit inlines its plan and all its rules. [approval] marks a step that needs the merchant's approval.

### Checkout readiness (`dashboard.checkout-readiness`)
ops: dashboard.checkout.flow_get -> dashboard.checkout.readiness_get -> dashboard.payments.methods_get -> dashboard.shipping_methods.list -> storefront.checkout.get_config
- Fail closed when any authoritative checkout setting cannot be read.

### Configure payment methods (`dashboard.payment-methods`)
ops: dashboard.payments.methods_get -> dashboard.payments.methods_update -> storefront.checkout.get_config
- Read the complete payment-method configuration first.

### Update Stripe checkout settings (`dashboard.stripe-settings`)
ops: dashboard.payments.stripe_get -> dashboard.payments.stripe_update
- Read masked settings; dashboard.payments.stripe_update declares only enabled, publishableKey, secretKey, and webhookSecret. Ask/no write for any ab...

### Create a shipping zone (`dashboard.shipping-method`)
ops: dashboard.shipping_zones.create -> dashboard.shipping_methods.list -> storefront.shipping_methods.list
- Require the merchant's zone name, its countries, regions, postal-code prefixes or existing Bangladesh places, charge name, fee, optional free-over ...

### Connect a delivery provider (`dashboard.delivery-provider`)
ops: dashboard.settings_providers.list -> dashboard.delivery_providers.create -> dashboard.delivery_providers.test
- Every courier is an app's (<plugin id>:<provider id>); its keys live in the app's settings, never on the provider.

### Import delivery locations (`dashboard.delivery-location-import`)
ops: dashboard.delivery_locations.import
- Send at most the import's chunk size per call, parents before children.

### Configure a tax rate (`dashboard.tax-configuration`)
ops: dashboard.taxes.settings_get -> dashboard.taxes.regions_list -> dashboard.taxes.regions_create -> dashboard.taxes.jurisdictions_list -> dashboard.taxes.classes_list -> dashboard.taxes.rates_create -> dashboard.taxes.preview -> dashboard.taxes.rates_list
- The store collects tax only where it has a region: an address in a country without one pays no tax.

### Invite a team member (`dashboard.team-invite`)
ops: dashboard.team.roles.list -> dashboard.team.users.invite -> dashboard.team.users.list
- Resolve an existing least-privilege role for the stated duties.

### Set up a new store (`dashboard.store-setup`)
ops: dashboard.settings.store_setup_get -> dashboard.settings.store_setup_apply
- Read the setup status first; when it is not needed, stop and use Settings -> Store details and Settings -> Markets instead.

### Change the store time zone or units (`dashboard.store-defaults`)
ops: dashboard.settings.store_defaults_get -> dashboard.settings.store_defaults_update
- Read the store defaults and their revision; save only the requested fields at that revision.

### Sell a market in its own currency (`dashboard.market-currency`)
ops: dashboard.markets.currencies -> dashboard.markets.list -> dashboard.markets.get -> dashboard.markets.update
- The backup market always sells in the shop currency; another market sells in it or in its own currency.

### Update checkout flow (`dashboard.checkout-flow-replace`)
ops: dashboard.checkout.flow_get -> dashboard.checkout.flow_update -> storefront.checkout.get_config
- Read the complete versioned checkout flow before editing.

### Conditionally enable guest access (`dashboard.guest-checkout-conditional-enable`)
ops: dashboard.checkout.flow_get -> dashboard.checkout.readiness_get -> dashboard.payments.methods_get -> dashboard.shipping_methods.list -> dashboard.checkout.flow_update -> storefront.checkout.get_config
- Read the complete versioned checkout flow and authoritative readiness before editing.

### Bangladesh checkout setup (`dashboard.bangladesh-checkout-supported-setup`)
ops: dashboard.settings.currency_get -> dashboard.payments.methods_get -> dashboard.shipping_methods.list -> dashboard.checkout.flow_get -> dashboard.settings.currency_update -> dashboard.settings_providers.list -> dashboard.payments.methods_update -> dashboard.shipping_zones.create -> dashboard.shipping_zones.update -> dashboard.checkout.readiness_get -> dashboard.checkout.flow_update -> storefront.checkout.get_config -> storefront.shipping_methods.list
- Dhaka time and mandatory phone stay fixed.

### Update customer notification rules (`dashboard.notification-rules`)
ops: dashboard.notifications.customer_rules_get -> dashboard.notifications.customer_rules_update
- Read the complete current rule set before editing.

### Manage webhooks (`dashboard.webhooks-manage`)
ops: dashboard.webhooks.list -> dashboard.webhooks.get -> dashboard.webhooks.create -> dashboard.webhooks.update -> dashboard.webhooks.delete[approval] -> dashboard.webhooks.rotate_secret -> dashboard.webhooks.test -> dashboard.webhooks.deliveries_list -> dashboard.webhooks.delivery_retry -> dashboard.events.list
- Endpoints receive order, customer and product data: confirm the exact HTTPS URL and topics with the merchant before creating or widening one.

### Install, update or stop apps (`dashboard.apps-install`)
ops: dashboard.apps.registry_list -> dashboard.apps.registry_settings_get -> dashboard.apps.registry_install -> dashboard.apps.update -> dashboard.apps.stop -> dashboard.apps.stop_third_party -> dashboard.apps.get
- Install and update only when installMode is dashboard (Workers Paid); otherwise give the merchant the installCommand.
