Generated by scripts/generate-recipes.mjs from the operation manifest and workflow catalog 3.0.0; do not edit.
scalius_search ranks these; a confident hit inlines its plan and all its rules. [approval] marks a step that needs the merchant's approval.

### Manage installed apps (`dashboard.apps-manage`)
ops: dashboard.apps.list -> dashboard.apps.surfaces -> dashboard.apps.get -> dashboard.apps.features_list -> dashboard.apps.feature_disable -> dashboard.apps.logs_list -> dashboard.apps.deliveries_list -> dashboard.apps.delivery_retry -> dashboard.apps.settings_update -> dashboard.apps.deactivate -> dashboard.apps.uninstall
- Apps read and change store data under their approved access; approving an app or an update that asks for more is the Super Admin's step in the dash...

### Narrow an agent grant (`dashboard.agent-grant-narrow`)
ops: dashboard.agent_access.connections.get -> dashboard.agent_access.grants.update
- Read the exact connection and its current authority first.

### Revoke an account session (`dashboard.account-sessions`)
ops: dashboard.account.sessions.list -> dashboard.account.sessions.revoke
- List sessions and resolve the exact non-current target first.

### Import or export store data (`dashboard.store-migration`)
ops: dashboard.import.products_batch -> dashboard.import.product_images_batch -> dashboard.import.customers_batch -> dashboard.import.inventory_batch -> dashboard.export.products -> dashboard.export.inventory
- Send a dry run first and show what will be created, updated and skipped; write only after the merchant confirms, passing each item's `expected` rev...

### Change many prices at once (`dashboard.bulk-price-change`)
ops: dashboard.resources.variants.bulk_set_prices -> dashboard.resources.bulk_runs.get
- Send dryRun: true first and show the before/after sample and totals; apply only after the merchant confirms.

### Set delivery charges (`dashboard.delivery-fees`)
ops: dashboard.shipping_methods.list -> dashboard.shipping_zones.apply_template -> dashboard.shipping_zones.update -> dashboard.shipping_zones.create
- Read the zones first: without zones, the Dhaka template creates inside/outside zones; then set each zone's rate.

### Issue a gift card (`dashboard.gift-card-issue`)
ops: dashboard.customers.list -> dashboard.gift_cards.create[approval] -> dashboard.gift_cards.list
- Confirm the amount and recipient with the merchant first; the card's code is shown once to staff and sent to the recipient, never to the agent.

### Launch setup checklist (`dashboard.setup-checklist`)
ops: dashboard.setup.checklist -> dashboard.checkout.readiness_get
- Report each open step with the operation it names; checkout readiness lists what blocks orders.

### Charge VAT or sales tax (`dashboard.vat-charge`)
ops: dashboard.taxes.regions_list -> dashboard.taxes.regions_create -> dashboard.taxes.rates_create -> dashboard.taxes.preview
- Create the country's tax region if it is missing, then its rate; whether prices include tax belongs to the market.
