scalius_search ranks these; a confident hit inlines its plan and all its rules. [approval] marks a step that needs the merchant's approval.

ops: storefront.search.predict -> storefront.products.list -> storefront.products.get_section
- Treat buyer-visible availabilityBand as stock truth; never claim an exact quantity.

- Use the resolved category ID, returned filter definitions, and declared pagination only.

### Edit a cart quantity (`storefront.cart-edit`)

- Use the exact variant and current context revision; never submit a client price or stock value.

### Read buyer checkout options (`storefront.checkout-options`)
ops: storefront.checkout.get_config -> storefront.checkout_language.get_active -> storefront.shipping_methods.list
- Report only active buyer-visible options and fail closed when configuration cannot be read.

### Complete a buyer checkout (`storefront.checkout-journey`)

- Resolve exact variant and delivery IDs, then thread the current context revision through each write.

### Authorize a customer (`storefront.customer-login`)

### Update a customer profile (`storefront.customer-profile`)

### Request order support (`storefront.order-support`)
